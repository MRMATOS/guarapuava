# Guarapuava Digital

Portal cívico hiperlocal progressivo para a população de **Guarapuava (PR)**, reunindo vagas de emprego atualizadas, radar de notícias do dia, mapeamento colaborativo de zeladoria urbana (*Cidade Viva*) e utilidades essenciais (horários de ônibus da Pérola do Oeste e guia de descarte ecológico).

## 🚀 Inicialização Rápida

```bash
# Instalar dependências
npm install

# Iniciar servidor local
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.
